## 🚀 Descripción del Proyecto
Desarrollo de un sistema integral para la gestión eficiente de pruebas radiológicas, agendas de trabajo y recursos técnicos del servicio asistencial. El sistema cuenta con una **arquitectura cliente-servidor multimódulo**, diseñada mediante el Proceso Unificado de Desarrollo (PUD) y apoyada por el uso de agentes de Inteligencia Artificial como asistentes de implementación bajo estricta auditoría humana.

## 🛠️ Stack Tecnológico
*   **Lenguaje:** Java 21
*   **Gestor de dependencias:** Maven (Arquitectura Multimódulo)
*   **Control de versiones:** Git Flow y Semantic Versioning
*   **CI/CD:** GitHub Actions
*   **Modelado:** Visual Paradigm y SysML
*   **Herramientas AI:** GitHub Copilot, Claude, Gemini (Bajo la directriz *"La IA implementa, el humano diseña y audita"*)

---

## ⚙️ Compilación y Ejecución
El proyecto está estructurado en módulos (contratos, seguridad, cliente, servidor, etc.). Para compilar el proyecto completo y ejecutar todas las pruebas automatizadas y verificaciones de dependencias, colócate en la raíz del repositorio y ejecuta:

```bash
mvn clean verify
```

*(Nota: La compilación validará las reglas de dependencias entre módulos y la cobertura de código como parte de nuestro plan de calidad).*
